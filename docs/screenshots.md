# Classic screenshots

The classic remake running with locally imported original artwork. Select a
screenshot to view it at its native 640 × 400 capture size. The additional
[PortMaster catalogue capture](screenshots/portmaster.png) renders the battle
at 640 × 480 with the 640 × 400 game view letterboxed, matching its intended
4:3 presentation. It was captured from Linux, not from another handheld.
Release packaging also derives a 320 × 200 muOS thumbnail from `battle.png`.

Captured from the Godot 4.6.1 Linux Compatibility renderer. Scenes are staged
for documentation using the normal game presentation. These images illustrate
the current build; they do not establish a complete campaign playthrough or
original-game accuracy.
